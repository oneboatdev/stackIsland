docs 根目录是整个博客文档的根目录，用于组织和存放各类技术文章的Markdown文件。

【文件夹说明】

1. fundamentals/
   - 计算机基础知识目录，包括计算机导论、组成原理、操作系统、计算机网络等基础内容

2. programming/
   - 编程语言学习目录，涵盖Java、Go、Python、前端等主流编程语言的学习笔记

3. frameworks/
   - 框架与中间件目录，包括MySQL、Redis、消息队列、Spring生态等主流框架和中间件的使用指南

4. architecture/
   - 架构设计目录，包含分布式系统、高并发、微服务等架构相关的理论与实践

5. engineering/
   - 工程实践目录，记录实际工作中的问题排查、性能优化、踩坑复盘等经验总结

6. devops/
   - 工程效能目录，包括Git版本控制、Maven/Gradle构建工具、CI/CD、监控诊断等开发运维相关知识

7. algorithms/
   - 算法与数据结构目录，包含各类数据结构、排序算法、算法思想、LeetCode刷题记录等内容

8. ai-bigdata/
   - AI与大数据目录，涵盖大模型基础、AI工程化、Flink流处理、Spark计算框架等大数据与AI相关技术

9. cloud-native/
   - 云原生目录，包括Docker容器化、Kubernetes容器编排、Service Mesh等云原生相关技术

10. guide/
    - 博客导读目录，包含博客结构说明和学习路径建议

【文件说明】

1. index.md
   - docs根目录的首页文件，通常用于展示文档目录概览或重定向到其他页面

【导航栏对应关系】

docs目录下的文件夹与导航栏的一级菜单一一对应，每个一级菜单下的子文件夹对应导航栏的二级菜单，以此类推形成完整的博客知识体系导航结构。
