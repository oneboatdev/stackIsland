spring 目录存放Spring生态相关的学习笔记，涵盖Spring、Spring MVC、Spring Boot、Spring Cloud等。

【文件夹说明】

1. spring/
   - Spring框架核心目录，包含IoC容器、AOP、Bean生命周期等Spring核心概念

2. spring-mvc/
   - Spring MVC目录，记录Spring MVC的请求处理流程、数据绑定、视图解析等内容

3. spring-boot/
   - Spring Boot目录，包含快速入门、自动配置、Starter原理等Spring Boot核心知识

4. spring-cloud/
   - Spring Cloud目录，涵盖服务注册与发现、配置中心、熔断器等微服务架构组件

【文件说明】

1. index.md
   - spring目录的首页文件，汇总展示Spring生态的各个模块

【导航栏对应关系】

本目录对应导航栏"框架与中间件"下的"Spring生态"菜单项（作为三级菜单组），其下的spring、spring-mvc、spring-boot、spring-cloud作为四级菜单项。
