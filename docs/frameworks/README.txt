frameworks 目录存放框架与中间件的学习笔记，涵盖MySQL、Redis、消息队列、Spring生态等主流框架和中间件。

【文件夹说明】

1. mysql/
   - MySQL数据库目录，包含SQL基础、索引优化、事务隔离等MySQL相关知识

2. redis/
   - Redis缓存数据库目录，包含Redis数据结构、缓存策略、分布式锁等内容

3. message-queue/
   - 消息队列目录，记录Kafka、RabbitMQ、RocketMQ等主流消息队列的使用和原理

4. spring/
   - Spring生态目录，包含Spring、Spring MVC、Spring Boot、Spring Cloud等Spring全家桶的学习笔记

【文件说明】

1. index.md
   - frameworks目录的首页文件，汇总展示框架与中间件的各个模块

【导航栏对应关系】

frameworks对应导航栏的"框架与中间件"一级菜单，其下的mysql、redis、message-queue、spring分别对应二级菜单项，spring下还有更细的三级分类。
