cloud-native 目录存放云原生相关的学习笔记，涵盖Docker容器化、Kubernetes容器编排、Service Mesh等云原生技术。

【文件夹说明】

1. docker/
   - Docker容器化目录，包含Docker基础、镜像构建、Dockerfile、Docker Compose等Docker核心技术

2. kubernetes/
   - Kubernetes目录，记录K8s的核心概念（Pod、Deployment、Service）、集群管理、 Helm等

3. container-network/
   - 容器网络目录，讲解Docker网络模式、K8s网络策略、Service Mesh网络等容器网络技术

4. service-mesh/
   - Service Mesh目录，记录Istio、Linkerd等Service Mesh解决方案的原理和使用

5. cloud-native-design/
   - 云原生架构设计目录，总结云原生应用的设计原则、架构模式和最佳实践

【文件说明】

1. index.md
   - cloud-native目录的首页文件，汇总展示云原生的各个模块

【导航栏对应关系】

cloud-native对应导航栏的"云原生"一级菜单，其下的docker、kubernetes、container-network、service-mesh、cloud-native-design分别对应二级菜单项。
