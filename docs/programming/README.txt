programming 目录存放编程语言学习笔记，涵盖Java、Go、Python、前端等主流编程语言。

【文件夹说明】

1. java/
   - Java编程语言目录，包含基础语法、集合框架、并发编程、JVM、Java新特性等内容

2. go/
   - Go编程语言目录，包含基础语法、并发模型、GMP模型、标准库等内容

3. python/
   - Python编程语言目录，包含基础语法、脚本开发等内容

4. frontend/
   - 前端技术目录，包含JavaScript/TypeScript、浏览器原理、前端工程化、框架等内容

【文件说明】

1. index.md
   - programming目录的首页文件，汇总展示各类编程语言的学习笔记

【导航栏对应关系】

programming对应导航栏的"编程语言"一级菜单，其下的java、go、python、frontend分别对应四个二级菜单项，每个语言目录下还有更细的三级分类。
