frontend 目录存放前端技术的学习笔记，涵盖JavaScript、TypeScript、浏览器原理、前端工程化、主流框架等。

【文件夹说明】

1. javascript/
   - JavaScript和TypeScript目录，包含ES6+新特性、异步编程、TypeScript基础等内容

2. 浏览器原理/
   - 浏览器工作原理目录，讲解浏览器渲染引擎、事件循环、性能优化等底层原理

3. engineering/
   - 前端工程化目录，包含模块化、打包工具（Webpack/Vite）、测试、CI/CD等工程化实践

4. frameworks/
   - 前端框架目录，记录React、Vue、Angular等主流前端框架的使用和原理

【文件说明】

1. index.md
   - frontend目录的首页文件，汇总展示前端技术的各个模块

【导航栏对应关系】

本目录对应导航栏"编程语言"下的"前端"菜单项（作为三级菜单组），其下的javascript、浏览器原理、engineering、frameworks作为四级菜单项。
