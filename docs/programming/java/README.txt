java 目录存放Java编程语言的详细学习笔记，涵盖Java的各个方面。

【文件夹说明】

1. basic-syntax/
   - Java基础语法目录，包含变量与数据类型、运算符、控制流程、数组、方法等基础知识

2. collections/
   - Java集合框架目录，包含List、Set、Map接口以及Collections工具类的使用详解

3. concurrency/
   - Java并发编程目录，包含线程基础、同步机制、并发容器、Executor框架等并发相关内容

4. jvm/
   - JVM目录，包含JVM内存模型、垃圾回收、类加载机制等JVM相关知识

5. new-features/
   - Java新特性目录，记录Java各版本的新特性和更新内容

【文件说明】

1. index.md
   - java目录的首页文件，汇总展示Java学习的各个模块

【导航栏对应关系】

本目录对应导航栏"编程语言"下的"Java"菜单项（作为三级菜单组），其下的basic-syntax、collections、concurrency、jvm、new-features作为四级菜单项。
