go 目录存放Go编程语言的学习笔记，涵盖Go语言的基础语法和核心特性。

【文件夹说明】

1. basic-syntax/
   - Go基础语法目录，包含Go语言的基本语法、数据类型、控制结构等基础知识

2. concurrency/
   - Go并发模型目录，包含Goroutine、Channel、Select等Go并发编程核心概念

3. gmp/
   - GMP模型目录，深入讲解Go的调度器实现原理（Goroutine、Machine、Processor）

4. stdlib/
   - Go标准库目录，记录Go标准库中常用包的使用方法和示例

【文件说明】

1. index.md
   - go目录的首页文件，汇总展示Go语言学习的各个模块

【导航栏对应关系】

本目录对应导航栏"编程语言"下的"Go"菜单项（作为三级菜单组），其下的basic-syntax、concurrency、gmp、stdlib作为四级菜单项。
