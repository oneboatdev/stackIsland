engineering 目录存放工程实践相关的学习笔记，记录实际工作中的问题排查、性能优化、踩坑复盘等经验总结。

【文件夹说明】

1. troubleshooting/
   - 线程问题排查目录，记录Java多线程、并发相关问题的排查思路和解决方法

2. performance/
   - 性能优化案例目录，分享系统性能优化实践，包括SQL优化、缓存优化、JVM调优等案例

3. cases/
   - 并发问题解决目录，汇总实际项目中遇到的并发问题及其解决方案

4. lessons/
   - 踩坑与问题复盘目录，记录技术选型踩坑经历、项目问题复盘总结等

【文件说明】

1. index.md
   - engineering目录的首页文件，汇总展示工程实践的各个模块

engineering对应导航栏的"工程实践"一级菜单，其下的troubleshooting、performance、cases、lessons分别对应二级菜单项。
