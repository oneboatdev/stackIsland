distributed 目录存放分布式系统相关的学习笔记。

【文件夹说明】

1. theory/
   - 分布式理论目录，包含CAP定理、BASE理论、一致性协议等分布式系统基础理论

2. transaction/
   - 分布式事务目录，记录2PC、3PC、TCC等分布式事务解决方案的原理和实现

3. lock/
   - 分布式锁目录，包含Redis分布式锁、Zookeeper分布式锁等实现方式和应用场景

【文件说明】

1. index.md
   - distributed目录的首页文件，汇总展示分布式系统的各个模块

【导航栏对应关系】

本目录对应导航栏"架构设计"下的"分布式系统"菜单项（作为三级菜单组），其下的theory、transaction、lock作为四级菜单项。
