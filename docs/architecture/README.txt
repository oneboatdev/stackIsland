architecture 目录存放架构设计相关的学习笔记，涵盖分布式系统、高并发、微服务等架构理论与实践。

【文件夹说明】

1. distributed/
   - 分布式系统目录，包含分布式理论（CAP、BASE）、分布式事务、分布式锁等分布式相关知识

2. distributed-components/
   - 分布式组件目录，记录Zookeeper、Etcd等分布式协调组件的使用和原理

3. high-concurrency/
   - 高并发设计目录，包含并发模型、缓存策略、异步化等高并发场景的设计思路

4. microservices/
   - 微服务架构设计目录，讲解微服务拆分、服务网格、API网关等微服务相关主题

5. service-governance/
   - 服务治理目录，包含服务限流、熔断降级、链路追踪等微服务治理策略

【文件说明】

1. index.md
   - architecture目录的首页文件，汇总展示架构设计的各个模块

【导航栏对应关系】

architecture对应导航栏的"架构设计"一级菜单，其下的distributed（及其子目录）、high-concurrency、microservices、service-governance、distributed-components分别对应二级菜单项。
