algorithms 目录存放算法与数据结构相关的学习笔记，涵盖各类数据结构、常见算法、算法思想等内容。

【文件夹说明】

1. data-structures/
   - 数据结构基础目录，包含链表、树、堆、图等基础数据结构的原理和实现

2. common-algorithms/
   - 常见算法目录，记录排序算法、查找算法、字符串匹配算法等常用算法

3. algorithm-thinking/
   - 算法思想目录，包含分治、贪心、回溯、动态规划等算法思想的讲解和应用

4. math/
   - 程序员数学目录，记录与编程相关的高等数学、线性代数、概率论等数学知识

5. leetcode/
   - LeetCode刷题记录目录，按题型或难度分类记录LeetCode题目分析和解答

【文件说明】

1. index.md
   - algorithms目录的首页文件，汇总展示算法与数据结构的各个模块

【导航栏对应关系】

algorithms对应导航栏的"算法与数据结构"一级菜单，其下的data-structures、common-algorithms、algorithm-thinking、math、leetcode分别对应二级菜单项。
