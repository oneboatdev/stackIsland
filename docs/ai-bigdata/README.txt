ai-bigdata 目录存放AI与大数据相关的学习笔记，涵盖大模型、AI工程化、流处理、计算框架等大数据与AI相关技术。

【文件夹说明】

1. llm/
   - 大模型基础目录，记录大语言模型（LLM）的基本原理、Prompt工程、微调技术等

2. ai-engineering/
   - AI工程化目录，包含MLOps、模型部署、模型监控等AI系统工程建设实践

3. vector-db/
   - 向量数据库目录，记录向量数据库（如Milvus、Pinecone）的使用和向量检索技术

4. flink/
   - Flink流处理目录，包含Flink的基本概念、DataStream API、状态管理、窗口计算等

5. spark/
   - Spark计算框架目录，记录Spark RDD、DataFrame、Spark SQL、流处理等核心知识

【文件说明】

1. index.md
   - ai-bigdata目录的首页文件，汇总展示AI与大数据的各个模块

【导航栏对应关系】

ai-bigdata对应导航栏的"AI与大数据"一级菜单，其下的llm、ai-engineering、vector-db、flink、spark分别对应二级菜单项。
