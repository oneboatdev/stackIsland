devops 目录存放工程效能相关的学习笔记，包括Git版本控制、构建工具、CI/CD、监控诊断等开发运维相关知识。

【文件夹说明】

1. git/
   - Git使用与进阶技巧目录，包含Git基本操作、分支管理、冲突解决、Gitflow工作流等内容

2. maven-gradle/
   - Maven和Gradle构建工具目录，记录Java项目的构建配置、依赖管理、插件使用等

3. ci-cd/
   - CI/CD目录，包含Jenkins、GitLab CI等持续集成/持续部署工具的使用和流水线配置

4. monitoring/
   - 监控与诊断目录，记录APM工具、日志系统、监控告警等线上问题诊断手段

【文件说明】

1. index.md
   - devops目录的首页文件，汇总展示工程效能的各个模块

【导航栏对应关系】

devops对应导航栏的"工程效能"一级菜单，其下的git、maven-gradle、ci-cd、monitoring分别对应二级菜单项。
